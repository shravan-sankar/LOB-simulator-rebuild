# Limit Order Book Simulator - Shravan Sankar

A C++ Limit Order Book and Matching Engine built to understand how trading systems process orders and execute trades.

Originally built in C++17 as an experiment to understand C++ semantics and the fundamentals of eTrading systems. The project is currently being rebuilt and developed towards modern C++20/23.

---

_**The previous LOB simulator has been archived. This project is a complete rebuild, with all original goals and planned functionality being implemented here with a greater focus on using modern C++ for the design.**_

---

## Current Goals

- Implement a Limit Order Book using price-time priority
- Support order placement and cancellation
- Implement trade execution and matching
- Support partial fills
- Handle limit and market orders
- Explore efficient data structures for processing market activity
- Develop a deeper understanding of performance and system design
